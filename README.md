# Customer Churn Prediction & Analysis

This project performs Data Cleaning, Exploratory Data Analysis (EDA), and Classification Modeling to predict customer churn using Machine Learning.

## 📌 Project Overview
* **Objective:** Identify potential churn customers to help businesses take proactive retention steps.
* **Dataset Size:** ~175,000+ records
* **Key Tasks:**
  * Data Cleaning and Preprocessing
  * Train/Test Label Distribution Analysis
  * Feature Selection & Feature Engineering
  * Predictive Modeling & Evaluation

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib/Seaborn
* **Environment:** Jupyter Notebook / VS Code

## 📊 Dataset Distribution
* **Train Set:** Balanced distribution across target classes.
* **Test Set:** Maintained class proportions for accurate validation.
